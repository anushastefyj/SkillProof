# SkillProof

SkillProof is a web application designed to help students showcase and verify their technical skills through projects, coding tasks, quizzes, and other forms of evidence.

## Features

* Student profile management
* Technical skill tracking
* Project showcase
* Coding task evidence
* Quiz-based skill assessment
* GitHub project integration
* Skill evidence management
* User authentication using JWT
* MongoDB database
* REST API backend
* Responsive React frontend

## Technology Stack

### Frontend

* React
* Vite
* JavaScript
* HTML
* CSS
* Axios

### Backend

* Node.js
* Express.js
* REST API
* JWT Authentication
* bcrypt

### Database

* MongoDB
* MongoDB Atlas

### Deployment

* Frontend: Vercel
* Backend: Render
* Database: MongoDB Atlas




## Installation

### 1. Clone the repository

```bash
git clone https://github.com/anushastefyj/SkillProof.git
```

### 2. Move into the project

```bash
cd SkillProof
```

### 3. Install frontend dependencies

```bash
cd client
npm install
```

### 4. Install backend dependencies

Open another terminal:

```bash
cd server
npm install
```
